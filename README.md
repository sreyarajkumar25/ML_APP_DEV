# ML_APP_DEV

ML Learn is an offline Android learning app built with Kotlin and Jetpack Compose.

## Phase 1

All ten topics are implemented with Theory and Playground tabs, offline Kotlin engines, interactive controls, live plots, and result summaries. The topic engines use only Kotlin math and have no Compose or Android dependencies.

## Build

Open this project in Android Studio with Android SDK Platform 34 installed, then run the `app` configuration on an emulator or device. From a terminal with the Android SDK configured, run `gradle :app:assembleDebug`.
